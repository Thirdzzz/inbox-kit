# 收件箱

这是你给 Agent 提需求的地方。在下面的需求区写一个 `## 标题`，再写几行你想要的效果就行；也可以运行 `$inbox-intake`（Codex）或 `/skill:inbox-intake`（pi），让 Agent 帮你把话整理成详细条目。

- 调度：运行 `$inbox` 或 `/skill:inbox`。Agent 会给每条需求编号、开发、检查、合并，并在标题前标出状态。
- 状态：{{statuses}}。
- 回复：在某条需求下加一行 `> 回复：…`，下次调度会读到。`待检查` 的需求回复「通过」就合并，回复「打回：原因」就返工。
- 草稿：标题带 `[草稿]` 的条目不会被处理，写完再去掉。
- 详情：每条需求的完整记录在 `inbox/NNN-标题.md`，这里只保留索引。
